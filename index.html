Step 1. Connect Gmail. Read only and safe

This site asks Google for read only access to Gmail. It can download mail. It cannot send mail. It cannot delete mail. It cannot change anything. It never asks for your password.

It can do this: list and read mails you pick, with attachments.
It cannot do this: send mail, delete mail, change labels, see your password.
You can sign out and remove access at any time with the button below, or in your Google Account under Security.

Saved in this browser only. Never sent anywhere except to Google sign in servers. If the site owner put it in config.js, you can leave this alone.

How to get a Client ID. Five minutes. Free.
  1. Go to Google Cloud Console. Make a project. Any name will do, like gmail archive.
  2. Open APIs and Services, then Library. Turn on Gmail API.
  3. Open OAuth consent screen. Pick External. Fill app name and your email. Add the scope gmail.readonly. Add yourself under Test users.
  4. Open Credentials. Create Credentials, then OAuth client ID. Type is Web application.
  5. Under Authorized JavaScript origins add:
    • https://YOURNAME.github.io
    • http://localhost:8000
  6. Copy the Client ID. It ends with apps.googleusercontent.com. Paste it above. Full steps are in OAUTH_SETUP.md in the repo.

Seeing Access blocked or Error 403. Add your Gmail as a Test user on the consent screen, or publish the app.

Privacy in plain words

Your mails come from Google straight into this page. They are packed into a ZIP you download. There is no server. No stats. No uploads. Sign out clears the token from this browser. The token is never written to logs.

Step 2. Pick which mails to save

Type one or more sender addresses. Add dates if you want. Then preview. If one mail matches, the full thread comes with it, with all replies. So nothing is missing.

How dates work
  • Start date means from 00:00 UTC on that day.
  • End date means through the full day to 23:59 UTC. Gmail treats end dates as not included, so the app adds one day to the search and checks each mail again.
  • Threads. If any mail in a thread matches, the full thread is saved. All replies from all people. Sorted oldest first. So the last count can be larger than the match count.

Step 4. Options

All of this is optional. Defaults are fine for most people. Originals plus a PDF you can read plus attachments saved on the side.

Videos are never stuck in the PDF. The PDF would get huge. The PDF shows the file name instead.

What you get in the ZIP
  • master-archive.pdf. One file you can read. Cover, list of mails, each mail with headers and text, notes for attachments.
  • emails/. Originals, sorted by sender and chat.
  • attachments/. Original files.
  • manifest.csv. Sheet with IDs, dates, subjects, file names, state.
  • checksums.sha256. Hashes to check nothing changed. Run sha256sum -c checksums.sha256.
  • export.log, errors.json, README.txt. What ran, what failed.

If anything fails, the app says INCOMPLETE. It will not say done when files are missing. You can run it again. It only reads from Gmail. It never changes Gmail.

      Access blocked or 403 or sign in loops
      
      Your Google Cloud consent screen is in Testing mode and your address is not a Test user, or the JavaScript origin is missing. Add your Gmail as a Test user and add https://YOURNAME.github.io to Authorized JavaScript origins. Then try an Incognito window.
      
    
      
    
      The app says INCOMPLETE
      
      Most times this is a short net cut or Gmail rate limit. Press Build my archive again. It is safe. It reads again. For big mail boxes, lower Max mails and run smaller date ranges.
      
    
      
    
      Where do my files go
      
      Into the ZIP you download. Most times it lands in your Downloads folder. Nothing stays on a server. The ZIP layout is listed in Step 4.
      
    
      
    
      The GitHub Pages site shows 404
      
      Make the repo public. Free GitHub accounts cannot host Pages sites from private repos. Then in Settings open Pages and pick Source GitHub Actions. Wait for the Actions run to turn green. Then reload the site address.
