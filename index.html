Step 1. Connect Gmail. Read only and safe

This site asks Google for read only access to Gmail. It can download mail. It cannot send mail. It cannot delete mail. It cannot change anything. It never asks for your password.

It can do this: list and read mails you pick, with attachments.
It cannot do this: send mail, delete mail, change labels, see your password.
You can sign out and remove access at any time with the button below, or in your Google Account under Security.
Access is by approval. Only selected users can sign in. If you are not approved you will see Access blocked. Type your Gmail below and press Send. You will get in after you are added.

No mail app needed. If sending fails here, email rednave.riddle@gmail.com from your Gmail instead.

Step 2. Pick which mails to save

Type one or more sender addresses. Add dates if you want. Then preview. If one mail matches, the full thread comes with it, with all replies. So nothing is missing.

How dates work
  • Start date means from 00:00 UTC on that day.
  • End date means through the full day to 23:59 UTC. Gmail treats end dates as not included, so the app adds one day to the search and checks each mail again.
  • Threads. If any mail in a thread matches, the full thread is saved. All replies from all people. Sorted oldest first. So the last count can be larger than the match count.

Step 4. Options

All of this is optional. Defaults are fine for most people. Originals plus a PDF you can read plus attachments saved on the side.

Videos are never stuck in the PDF. The PDF would get huge. The PDF shows the file name instead.

What you get in the ZIP
  • master-archive.pdf. One file you can read. Cover, list of mails, each mail with headers and text, notes for attachments.
  • emails/. Originals, sorted by sender and chat.
  • attachments/. Original files.
  • manifest.csv. Sheet with IDs, dates, subjects, file names, state.
  • checksums.sha256. Hashes to check nothing changed. Run sha256sum -c checksums.sha256.
  • export.log, errors.json, README.txt. What ran, what failed.

If anything fails, the app says INCOMPLETE. It will not say done when files are missing. You can run it again. It only reads from Gmail. It never changes Gmail.
