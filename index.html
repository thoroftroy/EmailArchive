Step 1 — Connect Gmail (read-only, safe)

This site asks Google for read-only access to Gmail. It can download messages, but it cannot send, delete, or change anything. Your password is never asked for or stored.

What the app can do: list & read emails and attachments you choose.
What it cannot do: send mail, delete mail, change labels, or see your password.
You can sign out / revoke access at any time (button below, or Google Account → Security → Third-party access).

Saved only in this browser (localStorage). Never sent anywhere except Google’s sign-in servers. If the site owner pre-filled it in config.js, you can leave this as-is.

How to get a Client ID (5 minutes, free — with pictures in OAUTH_SETUP.md)
  1. Go to Google Cloud Console → create a project (any name, e.g. “gmail-archive”).
  2. APIs & Services → Library → enable Gmail API.
  3. APIs & Services → OAuth consent screen → External → fill app name + your email → add scope …/auth/gmail.readonly → add yourself as a Test user.
  4. Credentials → Create Credentials → OAuth client ID → Application type Web application.
  5. Under Authorized JavaScript origins add:
    • https://YOUR-USERNAME.github.io
    • http://localhost:8000 (for local testing)
  6. Copy the Client ID (looks like …apps.googleusercontent.com) and paste it above. Full guide: OAUTH_SETUP.md.

Seeing “Access blocked / Error 403: access_denied”? Add your Gmail address as a Test user on the consent screen, or publish the app.

Privacy in plain English

Your emails are fetched from Google straight into this page and packed into a ZIP you download. There is no server: this is a static GitHub Pages site. No analytics, no uploads. Signing out discards the access token from this browser. The token is never written to logs.

Step 2 — Pick which emails to archive

Type one or more sender addresses, optionally narrow by date, then preview. Matching is done with Gmail search plus a careful date check, and whole conversation threads are included (replies from everyone) so nothing is missing.

Exactly how date filtering works
  • Start date means “from 00:00 UTC on that day onwards”.
  • End date means “through the whole day, up to 23:59 UTC” (Gmail’s before: is exclusive, so the app searches before:<end+1 day> and double-checks each message).
  • Threads: if any message matches, the entire thread (every reply, from every participant) is included and sorted oldest → newest. That is why the final count can be bigger than the “matching” count.

Step 4 — Customize your download

Everything is optional. Defaults are sensible for most people: originals + readable PDF + attachments saved separately.

Videos are never embedded in the PDF (it would become huge). The PDF shows a placeholder with the filename.

What you’ll get in the ZIP
  • master-archive.pdf — one big readable document: cover, contents, every message with headers + body, attachment notes.
  • emails/<sender>/<conversation>/*.eml — originals.
  • attachments/<sender>/* — originals in original formats.
  • manifest.csv — spreadsheet: message IDs, dates, subjects, filenames, status.
  • checksums.sha256 — hashes to verify nothing changed (sha256sum -c checksums.sha256).
  • export.log, errors.json, README.txt — what happened, what failed.

If anything fails, the app says INCOMPLETE — it never claims success when files are missing. Re-running is safe (it re-downloads; it never touches Gmail).

      I’m not technical. What do I do?
      
        
        
      1. Step 1: paste your Client ID (ask the site owner, or follow “How to get a Client ID”) → Sign in with Google.
        2.

        6. 
      
      
    
      
    
      “Access blocked”, 403, or sign-in loops
      
      Your Google Cloud OAuth consent screen is in Testing mode and your address isn’t a Test user, or the JavaScript origin is missing. Add your Gmail as a Test user and add https://YOUR-USERNAME.github.io to Authorized JavaScript origins. Then try an Incognito window.
      
    
      
    
      The app says INCOMPLETE / some files failed
      
      Usually a network hiccup or Gmail rate limit. Press Build my archive again (safe — it re-downloads). Big mailboxes: lower “Max messages” and run several smaller date ranges.
      
    
      
    
      Where do my files go?
      
      Into the ZIP you download — typically your Downloads folder. Nothing stays on any server. ZIP layout is documented in Step 4.
